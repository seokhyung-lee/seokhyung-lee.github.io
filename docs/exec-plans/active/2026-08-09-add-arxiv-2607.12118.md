# arXiv:2607.12118 publication 추가

## 요약

- [공식 arXiv 기록](https://arxiv.org/abs/2607.12118)과 제공된 [INSPIRE 레코드 3180564](https://inspirehep.net/literature/3180564)를 사용해 두 웹사이트에 동일한 preprint 항목을 추가한다.
- 첨부된 1210×1204 PNG를 수정·크롭하지 않고 동일한 썸네일로 사용한다.
- 작업 직전 두 저장소를 다시 `fetch`하고, 원격만 앞선 경우 fast-forward pull한다. 분기나 모호한 충돌이 발견되면 수정 전에 사용자에게 확인한다.

## 구현 변경

- 두 저장소의 `_bibliography/papers.bib` 2026년 항목 맨 앞에 `@misc{drouet2026error, ...}`를 추가한다.
- 제목, 저자 9명, 공식 초록과 함께 `year={2026}`, `month={Jul}`, `eprint/arxiv={2607.12118}`, `primaryClass={quant-ph}`, arXiv URL, `inspirehep_id={3180564}`, `prefix={Preprint}`를 기록한다.
- 첨부 파일을 두 저장소의 `assets/img/publication_preview/drouet2026error.png`로 복사하고 `preview` 필드에서 연결한다. 두 복사본은 원본 SHA-256 `b7ff4ca56e531949f40dbaee0a6b961c6f60ae5cbe79f008b73d4d10a28c7fb8`과 일치시킨다.
- 이미지 옆에 최소한의 provenance sidecar를 두어 2026-08-09 사용자 제공 스크린샷이며 해당 논문의 publication 썸네일 용도임을 기록한다.
- 별도 저널 DOI, Google Scholar ID, 뉴스 항목은 추가하지 않는다. 공개 API나 레이아웃 코드는 변경하지 않는다.

## 검증

- 각 저장소에서 arXiv ID, INSPIRE ID와 BibTeX 키가 정확히 한 번만 존재하고 두 BibTeX 항목이 동일한지 확인한다.
- 원본과 두 썸네일의 해시·PNG 형식·1210×1204 해상도를 확인한다.
- 두 저장소에서 Docker 기반 production Jekyll build를 실행한다.
- 생성된 publications 페이지에서 새 항목이 2026년 최상단에 나타나고, 저자·초록·Preprint 표기·arXiv/INSPIRE 링크·썸네일 및 Seok-Hyung Lee 강조가 정상인지 확인한다.
- 추적 파일 변경이 의도한 BibTeX·썸네일·출처 기록으로만 제한되는지 확인한다. 커밋과 push는 수행하지 않는다.

## 가정

- 첨부 이미지는 여백과 `Step 1` 문구를 포함한 현재 모습 그대로 사용한다.
- Docker 이미지나 필수 의존성이 없다면 임의 설치나 다른 빌드 방식으로 전환하지 않고 사용자에게 먼저 확인한다.
